# Busca CEP

Este projeto é uma aplicação feita em React que permite consultar informações de endereço baseadas em um CEP fornecido pelo usuário. Ele faz uso de APIs para buscar os dados relacionados ao CEP informado.

## Funcionalidades

- Permite ao usuário inserir um CEP para consulta.
- Retorna dados como logradouro, bairro, cidade e estado relacionados ao CEP.
- Valida o formato do CEP informado pelo usuário.

## Tecnologias Utilizadas

- Framework: React
- Linguagem: JavaScript
- Consumo de APIs RESTful
- Estilização: CSS

## Como Executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/Berla1/busca-cep.git
   ```

2. Navegue até o diretório do projeto:

   ```bash
   cd busca-cep
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie a aplicação:

   ```bash
   npm start
   ```

5. Acesse no navegador:

   ```
   http://localhost:3000
   ```

## Uso

- Abra a aplicação em seu navegador.
- Insira um CEP válido no campo de entrada.
- A aplicação consultará os dados do CEP e exibirá informações relacionadas como logradouro, bairro, cidade e estado.

---

A aplicação é uma ferramenta simples e eficaz para consultas de endereços baseados em CEP, ideal para projetos que necessitam dessa funcionalidade.
